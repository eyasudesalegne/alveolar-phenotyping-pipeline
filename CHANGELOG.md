# Changelog

## 0.2.0 — 2026-09-21

- Expanded the proof-of-concept into a modular Python package.
- Added deterministic multi-batch synthetic data generation with overlapping phenotypes.
- Added QC gates for focus, saturation, illumination and foreground fraction.
- Added watershed nuclear segmentation and approximate cell masks.
- Added single-cell morphology/intensity, population summaries and spatial features.
- Added batch-held-out interpretable modelling, calibration-sensitive metrics and bootstrap uncertainty.
- Added unit/integration tests and CI across Python 3.10–3.12.
- Added data contract, methods, validation, ethics/limitations and roadmap documentation.
- Added checked-in machine-readable synthetic benchmark results.
