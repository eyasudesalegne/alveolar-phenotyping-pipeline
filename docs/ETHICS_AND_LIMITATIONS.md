# Ethics, scope and limitations

This repository is research software for quantitative microscopy workflows. It is **not** a clinical device, diagnostic system, treatment recommender, or validated IPF biomarker model.

All repository-shipped demonstration data are synthetic. No patient, donor, hospital, or ICGEB experimental data are included.

The baseline segmentation and model are deliberately transparent and replaceable. Biological conclusions should only be drawn after assay-specific validation, independent experimental replication and review by the host biology team.

The intended use in the fellowship context is to demonstrate computational preparedness: reproducible QC, segmentation, phenotypic feature extraction, batch-aware validation and interpretable modelling that can later be adapted to real high-content screening data.
